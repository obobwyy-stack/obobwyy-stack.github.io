## 📝 Quick Reference Commands

### Development
```bash
cd ~/blog

# Create new post
hexo new "post-title"

# Local development

# Generate static files
npm run build
```

### Deployment
```bash
# After deployment setup
git add .

git push
# GitHub Actions handles deployment automatically
```

### Maintenance
```bash

# Clean cache
npm run clean
```
